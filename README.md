# HackerRank Solutions

This repository contains solutions to various challenges from the HackerRank platform, with detailed explanations to help learners understand the concepts.

## Repository Structure

- **sql/** - Solutions for SQL challenges
  - **basic/** - Solutions for basic SQL challenges, including SELECT queries, filtering, and aggregate functions
    - Each challenge includes a detailed README with step-by-step explanations in English

## Educational Approach

All solutions in this repository follow an educational approach:

- **Detailed Documentation**: Each solution includes a comprehensive README with:
  - Clear problem description
  - Input format and constraints
  - Step-by-step solution approach
  - Code explanation with comments
  - Expected output

- **Progressive Learning**: Challenges are organized to build skills progressively

## How to Navigate

Each folder contains a README.md with specific information about the challenges in that category. To explore a specific topic:

1. Navigate to the corresponding folder (e.g., `sql/basic/`)
2. Browse the available challenges
3. Each challenge folder contains:
   - A README.md with detailed explanation
   - Solution files in the appropriate language/format

## Technologies Used

- **SQL**: Standard SQL compatible with MySQL, MS SQL Server, and Oracle
- Other technologies will be added as new challenges are solved

## Docker Environment

For SQL challenges, a Docker environment is provided to help you test solutions locally. See the [sql/DOCKER.md](./sql/DOCKER.md) file for details.
