# Basic SQL Solutions

This folder contains solutions for HackerRank basic SQL challenges.

## Included Challenges

- **revising-the-select-query-1** - Basic query with WHERE filter
- **revising-the-select-query-2** - Query with multiple conditions
- **select-all** - Selecting all records
- **select-by-id** - Selection by specific ID
- **japansese-cities-names** - Filtering by city names
- **weather-observartion-station** - Series of challenges with weather data
- **name-of-employees** - Employee name queries
- **employees-salaries** - Salary queries
- **more-than-75-marks** - Filtering by marks above 75
- **what-type-of-triangle** - Triangle classification
- **the-pads** - String manipulation and sorting
- **occupations** - Data pivoting
- **average-population-of-each-continent** - Calculating averages by group

## How to Use

Each challenge folder contains a `solution.sql` file with the implemented solution. To test, simply run the SQL code in a compatible environment.
